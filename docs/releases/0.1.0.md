# QuietDeck 0.1.0

First release. Manage a Steam Deck from your Mac: pair it with no keyboard, then handle emulators, ROMs, Steam shortcuts, Decky, compat tools, saves and the Quiet theme for Game Mode.

Some parts have only been tested on a simulated Deck, including applying the theme. SMOKE_TEST.md has the list.

The app is signed ad-hoc, so macOS blocks the first launch. The README explains how to open it.
